# Instruções para agentes de IA

A cada alteração feita no código ou em arquivos deste repositório, realize **o commit e o push** automaticamente:

1. Adicione as mudanças: `git add -A`
2. Faça o commit com uma mensagem descritiva e concisa: `git commit -m "<mensagem>"`
3. Envie para o repositório remoto: `git push`

Sempre verifique `git status` antes e depois para confirmar que tudo foi registrado corretamente.
